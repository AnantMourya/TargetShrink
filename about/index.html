About TargetCompress

Empowering users with private, exact-target file compression directly on their devices.

Our Mission

Every day, millions of students, job seekers, and professionals encounter upload errors on portals with strict file size limits (e.g. "File must be under 50KB", "PDF must not exceed 200KB", or "Video cannot exceed 10MB"). Traditional online compressors offer vague percentage sliders like "50% compression" that force users into a frustrating cycle of guessing, checking, and re-compressing.

TargetCompress was created to fix this. Our goal is simple: let you specify the exact file size limit your portal requires, and let our mathematical optimization solvers achieve that target size on the very first try.

The Privacy-First Client-Side Architecture

Unlike traditional online file converters that require you to upload confidential tax records, identification scans, and personal videos to third-party cloud servers, TargetCompress executes 100% locally in your web browser.

How It Works Inside Your Browser:

  • WebAssembly (Wasm): High-performance binary modules (FFmpeg.wasm and PDF-Lib) compile directly to native CPU machine code inside your browser sandbox.
  • HTML5 Canvas API: Real-time hardware-accelerated image decoding and binary-search quantization solvers.
  • Zero File Uploads: Your files are converted in device RAM as local binary Blobs. No file bytes are ever uploaded or transmitted to our servers.

Free Forever, No Paywalls

We believe foundational digital utilities should be universally accessible. TargetCompress requires no user registration, imposes no daily document quotas, adds no ugly promotional watermarks, and never locks premium features behind a paywall.
